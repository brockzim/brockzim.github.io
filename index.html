Channel Uploader (personal)

Channel Uploader is a private tool used by its owner, Pedro Henrique de Jesus, to upload, schedule and read statistics for videos on his own YouTube channels. It is not offered to the public and has no other users.

It uses the YouTube Data API and the YouTube Analytics API through Google's official OAuth sign-in. It only acts on channels whose owner has signed in and granted permission.
